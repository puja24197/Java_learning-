# 💻 Java_learning

A collection of Java practice programs covering Object‑Oriented Programming (OOP) concepts, arrays, constructors, inheritance, and more.  
Created by **Puja Rani Paul** for learning and improving Java programming skills.

## 📚 Project Overview
This repository contains multiple Java programs that demonstrate core programming concepts such as:
- Abstraction  
- Encapsulation  
- Inheritance and Method Overriding  
- Constructors and Copy Constructors  
- Arrays and User Input  
- Factorial and String Manipulation  
- Object Passing and List Operations  

Each file focuses on a specific concept with clear examples and comments for better understanding.

## 🧠 How It Works
- Every `.java` file can be compiled and run individually.  
- Programs use the `Scanner` class for user input and `System.out.println()` for output.  
- Concepts are implemented through classes, methods, and loops to show real‑world usage of Java fundamentals.
