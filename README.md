# ArrayMix.java

### 📘 Project Overview
This Java program demonstrates **array creation, user input, and traversal**.  
It allows the user to:
1. Enter the size of an array.
2. Input elements one by one.
3. Display all elements with their index positions.

---

### 💻 How It Works
- The program uses the `Scanner` class to take input from the user.
- It dynamically creates an integer array based on the size entered.
- A `for` loop stores user inputs into the array.
- Another `for` loop prints all elements with their index.
